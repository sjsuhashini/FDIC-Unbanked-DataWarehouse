
# FDIC Unbanked Households Data Warehouse & Analytics ( https://github.com/sjsuhashini/FDIC-Unbanked-DataWarehouse/)
## End-to-End ETL + Data Warehouse + Power BI Solution
* Built a production-style Business Intelligence pipeline to analyze 10 years of FDIC Unbanked Household survey data (2013–2023) using SQL Server, SSIS, and Power BI.
* This project demonstrates data engineering, dimensional modeling, ETL automation, SQL analytics, and dashboard reporting.

Architecture
CSV Files → SSIS ETL → Staging Tables → Dimensions → Fact Table → SQL Views/KPIs → Power BI Dashboards

Tech Stack
* SQL Server
* SSIS (SQL Server Integration Services)
* T-SQL
* Star Schema Modeling
* Window Functions
* Power BI
